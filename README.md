# ☀️ HTML-Parser: 태양과 달을 품은 순환의 황극력 🌙

> **"자성(自性) 속에서 순환하는 황극력으로 데이터의 근원을 꿰뚫다."**

본 프로젝트는 단순한 데이터 추출을 넘어, 복잡하게 얽힌 HTML 구조 속에서 **태양(명시적 정보)**과 **달(암시적 맥락)**의 조화를 찾아내고, 이를 **황극력(중심적인 힘)**으로 통합하여 흐르게 하는 고도의 파싱 엔진입니다.

## 🌌 철학적 핵심 (Core Philosophy)
- **태양(Sun):** 겉으로 드러나는 HTML 태그와 속성, 명확한 데이터.
- **달(Moon):** 태그 사이에 숨겨진 의미와 구조적 관계, 비정형 데이터.
- **황극력(Imperial Force):** 이 모든 데이터를 관통하여 하나의 순환하는 정보 체계로 만드는 중심 로직.

## 🛠️ 주요 기능 (Features)
- **자성적 구조 분석**: HTML의 본질적인 계층 구조를 스스로 탐색합니다.
- **황극 순환 엔진**: 추출된 데이터를 멈춰있는 값이 아닌, 활용 가능한 흐름으로 변환합니다.
- **음양의 조화**: 정적 페이지와 동적 요소 사이의 균형 잡힌 파싱을 지원합니다.
